SeeThrough Helm Repository

This is the Helm chart repository for SeeThrough — a lightweight Kubernetes and server monitoring software.

Usage

helm repo add seethrough https://longucodes.github.io/seethrough/charts
helm repo update
helm search repo seethrough
helm install seethrough seethrough/seethrough

Channels

  • canary — Built from every push to master, versioned with a -canary-{sha} suffix
  • latest — Built from every v*.*.* tag
